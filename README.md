## Experiment 4: Sobel Edge Detection Accelerator

The Sobel accelerator performs edge detection using FPGA hardware. The design includes a 3×3 image window, MAC-based computation, parallel processing, and FPGA implementation components.

Detailed implementation files and results are available under `Experiment-4-Intermediate/`.
